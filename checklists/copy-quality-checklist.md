# Copy Quality Checklist

Baseado nos frameworks de Hormozi, Ogilvy, Schwartz, Sugarman e Halbert.

## Testes Universais (aplicar em CADA seção)

- [ ] **Teste "So What?"** — Cada frase responde "e daí?"
- [ ] **Teste "Who Cares?"** — Relevante para o público-alvo
- [ ] **Teste de Especificidade** — Números > adjetivos genéricos
- [ ] **Teste de Clareza** — Legível no nível 8th grade
- [ ] **Teste de Tom** — Consistente com as seções anteriores
- [ ] **Gramática e ortografia** — Zero erros

## Hero Section

- [ ] Headline com max 10 palavras
- [ ] Headline contém benefício principal (não feature)
- [ ] Headline passa no Hormozi Value Equation test
- [ ] Supporting copy expande o headline (não repete)
- [ ] CTA tem verbo de ação + benefício
- [ ] CTA é UMA ação específica (não genérico)

## Problem/Agitation

- [ ] Identifica a dor EXATA do público
- [ ] Usa linguagem do público (não jargão)
- [ ] Amplifica a dor com consequências reais
- [ ] NÃO exagera nem manipula
- [ ] Transição natural para solução

## Solution/Demo

- [ ] Form header com benefício (não "Preencha o formulário")
- [ ] Explica claramente o que recebe em troca
- [ ] CTA específico e irresistível
- [ ] GDPR text presente e claro

## Testimonials

- [ ] Resultados específicos com números
- [ ] Nome real + cargo + empresa
- [ ] Soa autêntico (não corporativo demais)
- [ ] Pelo menos 1 depoimento aborda objeção comum

## Benefits

- [ ] Títulos são RESULTADOS (não features)
- [ ] Descrições explicam COMO funciona
- [ ] Cada benefício é único (sem sobreposição)
- [ ] Ordem: mais impactante primeiro

## Features

- [ ] Cada feature conecta a um benefício
- [ ] Descrições são concisas (1-2 frases)
- [ ] Sem jargão técnico desnecessário

## Final CTA

- [ ] Repete a proposta de valor
- [ ] Urgência/escassez é GENUÍNA (não fabricada)
- [ ] Garantia reduz risco efetivamente
- [ ] CTA é impossível de ignorar

## Frameworks Aplicados

- [ ] **Hormozi:** Value Equation presente no hero
- [ ] **Schwartz:** Copy match awareness level do público
- [ ] **Sugarman:** Slippery slide — cada frase puxa a próxima
- [ ] **Ogilvy:** Headline investiu 80% do esforço de copy
- [ ] **Halbert:** "Reason why" copy em CTA e garantia
