# Escrever copy das seções

## Input
- `copy-research.md`
- `landing-page-plan.md`
- `templates/section-copy-template.md`
- `checklists/copy-quality-checklist.md`

## Steps
1. Escrever cada seção embarcada com o framework mapeado e o rationale numa linha.
2. Hero: headline ≤ 10 palavras, benefício, So What? / Who Cares?, CTA verbo + resultado.
3. Prova: números e nomes só do brief. Sem depoimento inventado. Sem face.
4. CTA nunca Submit / Clique aqui. Urgência só com razão (Halbert).
5. Rodar o checklist. Corrigir falhas. Gravar `section-copy.md`.

## Output
`section-copy.md` (slug `section-copy`).

## Acceptance Criteria
- [ ] Toda seção embarcada tem copy + framework + rationale
- [ ] Headline do hero ≤ 10 palavras e passa So What? / Who Cares?
- [ ] CTAs são verbo + benefício
- [ ] Nenhuma prova nomeada foi inventada; o que faltar está rotulado como premissa
- [ ] Checklist de copy sem item crítico aberto
